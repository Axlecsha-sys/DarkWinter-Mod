Онлайн работает по сообщению владельца. Лаунчер и отдельные возможности имеют ограничения, указанные в соответствующих руководствах. Успешная сборка не заменяет игровую или визуальную проверку.

Старые технические задания, промежуточные отчёты, raw prompts, концепты и локальные диагностические материалы сохранены вне публикуемой документации. Сохранения, профили и ключи в репозиторий не входят.
