# DarkWinter Launcher

Лаунчер — нативное Windows-приложение на Rust/egui в стиле сине-голубого полевого дневника. Текущий исходный этап ещё не является готовым дистрибутивом: установщик, подписанные обновления, подготовка игровой сборки, запуск Minecraft и Watchdog не завершены. Кнопка «Играть» недоступна с объяснением.

## Доступные возможности

- Нативные вкладки, профиль, диагностика и настройки; адаптация к узкому окну и масштабу 150%.
- Масштаб интерфейса и анимация сохраняются; снег приостанавливается при сворачивании и потере фокуса.
- Раздельные каталоги настроек, сборок, пользовательских данных, кэша и отчётов.
- Единственный писатель настроек и атомарная замена; повреждённый или неизвестный формат не заменяется автоматически.
- Определение Windows/CPU/ОЗУ и ограниченная проверка найденной Java.
- Чтение публичной части существующего профиля и локальный диагностический отчёт без экспорта секретных значений.

Чтение открытого ключа не доказывает владение секретным ключом, дружбу или текущий сетевой статус. Сетевые возможности мода не означают, что те же функции уже доступны в лаунчере.

## Сборка и запуск

Требуются Windows x64, Rust 1.99.1, MSVC C++ tools и Windows SDK. Версии закреплены в `rust-toolchain.toml` и `Cargo.lock`. Из каталога `darkwinter-launcher`:

```powershell
cargo build --release --locked
.\target\release\DarkWinterLauncher.exe --game-dir <каталог-игры>
```

`--game-dir` задаёт папку существующей игры. По умолчанию данные окна находятся в `%LOCALAPPDATA%\DarkWinterLauncher`; `--data-dir` изолирует проверочный запуск. Профили и сохранения игры не импортируются и не перемещаются.

Для диагностики доступен `--diagnose --game-dir <каталог-игры> --report <новый-файл.json>`, для явного выбора Java — `--java <путь>`. Родитель каталога отчёта должен существовать; существующий файл отчёта не заменяется.

## Интерфейс и ресурсы

Композиция интерфейса: холодная голубая бумага, зимняя панорама, тёмно-синяя типографика, правая колонка и синяя панель запуска. Изображения встроены отдельно, тексты и элементы управления рисуются egui, а не запечённым скриншотом интерфейса.

Georgia Bold читается из установленной Windows при наличии; иначе используется встроенный шрифт. Системные шрифты не копируются в дистрибутив. Происхождение нужных изображений отражено в [описании контента](../provenance/README_RU.md).
