# Visuals: рендерер и настройки

Нативный модуль расположен в [modules/darkwinter-visuals](../../modules/darkwinter-visuals/). Он входит в DarkWinter для Minecraft 26.3/Fabric/Java 25 и не требует отдельного shaderpack, Iris или Sodium.

Текущий порядок проходов: `surface → volume → composite → sky_clouds → sky_merge → film`. Контракт `DarkWinterScene` занимает 416 байт. Согласованность CPU/GLSL и ресурсов контролируется Pipeline Guard; успешная проверка ресурсов не является художественной приёмкой кадра.

## Настройка

Рендер запускается автоматически. Активный файл — `<каталог-игры>/config/darkwinter/visuals.properties`; для разработческого запуска это `run/config/darkwinter/visuals.properties`. [Шаблон конфигурации](../../modules/darkwinter-visuals/config/visuals.properties) не является второй живой копией.

Изменения перечитываются примерно раз в секунду. `enabled` отключает весь модуль; `shadows` — захват теней; `volume` — лучи; `atmosphere` — художественный film-проход. В тестовом мире действуют также переключатели его профиля. Команда `/posteffect add` не нужна.

Качество выбирается `quality=LOW|BALANCED|HIGH`. Профиль уменьшает объём работы, но не обещает конкретный FPS на любой видеокарте. Ключи `filmStrength`, `saturation`, `coldness`, `exposure`, `grain`, `chromaBleed`, `vignette` и аналоговые настройки задают кинопрофиль. Автоэкспозиция от яркого снега не заявляется.

`visualDayLengthMultiplier`, `sunSizeMultiplier` и `moonSizeMultiplier` относятся к визуальному небу; они не ускоряют и не останавливают серверные часы или календарь.

## Диагностика

| `debug` | Вид |
| --- | --- |
| 0 | Обычный кадр |
| 1 | Карта теней |
| 2 | Видимость поверхности для света |
| 3 | Сигнал лучей |
| 4 | Восстановленная дистанция |
| 5 | Восстановленные нормали |
| 6 | Маркер выполнения film-прохода |

`freezeSun=true` фиксирует направление света только для этого рендера и не останавливает ванильное солнце. После проверки верните `debug=0`. Изменение исходного GLSL само по себе не гарантирует обновление ресурсов запущенной игры; F3+T перечитывает фактически загруженные ресурсы.

## Ограничения

- Используется одна локальная карта теней; незагруженные секции не отбрасывают тень, у края покрытие ослабляется.
- Захват включает рельеф и скомпилированные opaque/cutout-слои; сущности и отдельные block-entity renderer в него не входят.
- Это не TAA и не физическое моделирование полутени; остаточный алиасинг мелкой растительности возможен.
- Полного разделения фонового, солнечного и факельного света нет.
- HUD и предметы первого лица рисуются после мировой цепочки и не получают её film-профиль.
- Цветные тени стекла, мокрые PBR-материалы и физическая симуляция ветвей не заявляются этим модулем.
- Погодный мост принимает состояние погоды; наличие моста не означает самостоятельную погодную симуляцию.

При проверке используйте сопоставимую сцену: обычный режим, фиксированный свет, движение камеры, отключённые тени; отдельно проверьте смену мира и перезагрузку ресурсов. При сбое нужна первая ошибка рендера, а не только последующее сообщение об отключении. Снимок экрана не измеряет плавность.
