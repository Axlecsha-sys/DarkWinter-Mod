# Происхождение контента

Здесь сохранена краткая связь необходимых игровых ресурсов с записями их подготовки. [ASSETS.json](ASSETS.json) содержит пути существующих файлов, текущие SHA-256 и семейство записи происхождения. Хеш фиксирует текущие байты, а не подтверждает неизменность первоначального результата генерации.

- Текстуры строительных материалов и мебели связаны с записанной генерацией встроенным imagegen и механическим уменьшением до игрового размера. Для обновления «недавняя катастрофа» использовалось отдельное описание поддерживаемого, недавно оставленного города.
- Источники хвои, коры и снега тестовой ели были приведены к 512/256/128 пикселям с сохранением RGBA. Полноразмерные дубли и raw prompts не нужны для загрузки игровых ресурсов.
- Фон главного меню `northern_lake.png` подготовлен как отдельная иллюстрация без элементов интерфейса.
- Изображения лаунчера подготовлены на основе утверждённого сине-голубого полевого дневника; производственные paper/panorama/wordmark хранятся отдельно от нативных элементов интерфейса.

Подробные prompts, промежуточные концепты, диагностические кадры и локальные результаты сохранены в частном архиве разработки и не включаются в публичную документацию. Эта сводка не выдаёт права на Minecraft, шрифты Windows или сторонние библиотеки.
