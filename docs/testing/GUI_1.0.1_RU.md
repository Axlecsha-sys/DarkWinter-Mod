# GUI/HUD DarkWinter 1.0.1: проверка клиента

**Итоговый отчёт на 2 ноября 2026 года. Область приёмки — русский язык, Windows и Vulkan.** Завершены 73 сценария меню, матрицы инвентаря и редактора, адресный прогон HUD/чата. Дополнительная доводка минимального GUI 320×240 и полная английская приёмка отложены.

Среда: Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.163.0+26.3, Java 25 x64, Windows, **Vulkan**. Проверка проведена в изолированной копии `develop/gui` от `ff360c0`; новые DV/DVCPP-изменения из других веток в неё не переносились. OpenGL в этом прогоне не проверяется.

## Что считается доказательством

- **Технический PASS** относится к конкретному переходу, событию ввода, состоянию или геометрии элементов. Он не означает художественную приёмку всего экрана.
- **Выборочный визуальный просмотр** относится только к перечисленным PNG. Наличие сотен сохранённых кадров не означает, что каждый из них просмотрен и принят.
- **NOT_RUN** обозначает сценарии вне завершённой области проверки.

Локальные материалы находятся в исключённом из Git `build/gui-evidence/`: `actions.jsonl`, PNG и JSON захватов. Журнал содержит время UTC, действие, экран до/после и принятие события; JSON кадра — SHA-256, номер кадра, размер render target и реальное GUI-дерево. Время UTC 1 ноября 19:xx соответствует 2 ноября 05:xx во Владивостоке. Значения скрытых полей не нужны отчёту и не публикуются. Представительные кадры включены ниже; полные материалы остаются локальными.

## Финальный адресный прогон

На итоговом коде повторены реальные клики GUI Auto → 1 → 2 с возвратом Auto и уменьшение Sound Options 3840×2160 → 854×480. Ошибок scissor нет. Экран паков выдержал живое изменение GUI 320 → 480 → 320: колонки 146 → 200 → 146, те же строки и штатные обработчики сохранены; описания перенесены внутри колонок. Частные bounds текстовых виджетов helper не экспортирует, поэтому их читаемость проверена по реальным PNG.

В отдельном тестовом острове включены HUD, погода, ветер и измерения. Длинное сообщение самому игроку переносится слева от лаборатории; диагностика уступает ему место и возвращается после 200 GUI-тиков. История открывается в ChatScreen. Проверены toast при HUD ON/OFF, инвентарь и Creative без пассивного чата, Wall Builder, F9 CHARACTER/SURVIVAL с возвратом EDIT и двухстрочная подпись погоды. Native хотбар 1–9 в игровом режиме сохраняется.

Пауза → соединения → возврат → Save and Quit прошли штатно. Открыта и отменена форма Free; диалог удаления запрашивался только для собственного временного мира и отменён. Исходные сохранения не изменялись.

## Границы проверки

При минимальном GUI **320×240** за инвентарём тестового мира виден фоновый штатный хотбар. Дополнительная доводка этого маленького варианта отложена; технические проверки слотов не означают его полную визуальную приёмку. Полная английская приёмка также отложена.

Не проверены OpenGL, реальные подключения к другому участнику, Realms, звук narrator, смена графического backend с перезапуском и все сложные операции истории/экспорта. Проверка состава архива не означает полный аудит условий native-зависимостей; существующие границы WebRTC/Iroh сохранены в их уведомлениях.
