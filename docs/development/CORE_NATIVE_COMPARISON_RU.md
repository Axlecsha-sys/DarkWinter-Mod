| Контактное освещение | Фигуры и ближние объекты выглядели плоскими | Короткие лучи ambient occlusion; дальность и число лучей ограничены, дополнительные лучи только возле контакта персонажа |

SVG для C++ экспортирует тот же SvgGeometry, которым пользуется мод: учитываются кривые, дуги и обводки. Новых сторонних игровых модов и чужих ассетов нет. Java нужна при сборке/экспорте, исполняемый клиент работает без JVM.

Новые миры используют генератор v2. Старые миры v1 продолжают использовать свой алгоритм; контрольный столбец seed 19971008 совпадает побайтово с прежней версией. Плотность леса в старом сохранении автоматически не меняется.

## Реальные ограничения сравнения

| Область | Что ещё отличается |
|---|---|
| Генерация мира | C++ использует собственный генератор, поэтому размещение деревьев, рельеф и распределение растений не повторяют мир Minecraft по seed |
| Свет и небо | Перенесены солнечное время, часть климатических формул и палитра; полный sky_clouds/sky_merge/film, объёмные облака, Луна и звёзды ещё не перенесены |
| Текстуры | Фильтрация и сглаживание мелкой хвои отличаются; на удалённых ветвях C++ заметнее зерно и алиасинг |
| Погода | Девять профилей, соседние переходы, температура и ветер адаптированы; последовательность случайных событий отличается от Minecraft; осадки и позёмки пока не перенесены |
| Анимация | Есть ходьба, рука и плечевая камера; нет полного набора предметных анимаций и всех реакций тела мода |
| Настройки | Показаны рабочие возможности C++ клиента. Количество параметров, прокрутка, языки и загрузочные экраны Minecraft пока не воспроизведены полностью; поддержан русский язык |
| Выживание | Работают выносливость и движение; остальные индикаторы ещё не означают полную симуляцию голода, жажды, усталости и переохлаждения |
| Инвентарь | Отложен по указанию автора |

Дневной C++ кадр снимается в отдельном тестовом сохранении с лабораторно заданной датой 17.10.1997 и ясной погодой. Это сближает условия с присланным эталоном, но сцена и расположение камеры не одинаковые. Снимки не редактировались для сокрытия расхождений.
