# Исправления по кадрам пользователя: язык и F3

3 ноября 2026 года пользователь прислал три игровых кадра после первого варианта `LANGUAGE_F3_QUALITY_RU.md`. В них обнаружены реальные дефекты, отсутствовавшие в браузерном превью:

1. F3 пересекается с погодой, лабораторным HUD и его отдельным графиком.
2. F3 рисуется поверх меню паузы.
3. Экран языка показывает рамку без поиска, списка и навигации.

## Причины и изменения

Пустой экран языка вызван исключением при создании `LanguageSelectionList`: журнал `run/logs/latest.log` содержит `@ModifyArg handler before super() invocation must be static`. Ошибка прерывает `OptionsSubScreen.init()` до регистрации элементов. Поэтому исчезает весь набор виджетов, а добавленная отдельно рамка продолжает отображаться.

Обработчик изменения высоты строки `SettingsLanguageListMixin.darkwinter$rowHeight` сделан статическим. То же исправление применено к аналогичному конструктору `DebugOptionsListMixin.darkwinter$height`. Оба обработчика меняют только константу высоты, состояние ещё не созданного объекта им не требуется.

Добавлен общий `DebugOverlayVisibility`:

- раскрытая F3 временно скрывает погоду/дату, индикаторы состояния, лабораторную панель и её график;
- состояние переключателей HUD, лаборатории и диагностики не меняется;
- сбор лабораторных времён кадра продолжается перед проверкой видимости;
- при закрытии F3 панели вновь отображаются по прежним правилам;
- при открытом меню F3 не извлекается, включая её графики; в игровом виде и чате остаётся доступной;
- открытие меню не выключает сам флаг F3: после выхода обратно в игру диагностика может вернуться.

Оформление, SVG-ресурсы, шейдеры, хоткеи, игровые показатели и механики не переделывались.

## Проверка без запуска игры

- `build/language-f3-fixes/build.log`: полная сборка прошла.
- `build/language-f3-fixes/UiMixinApplyCheck.java`: изолированный Fabric/Knot загружает 11 UI mixin и применяет их к 12 настоящим классам Minecraft 26.3. Классы разрешаются с `Class.forName(..., false, ...)`; основной метод игры не вызывается, окно, графическое устройство и мир не создаются. Проверены также статичность обоих добавленных обработчиков и установка проверки меню для F3.
- Это проверка реального применения выбранных mixin, а не только существования методов. Вспомогательный контейнер не имеет main/client/preLaunch entrypoint. Библиотеки Fabric API подключены как классы без регистрации дополнительных модов.
- `build/language-f3-fixes/mixin-before.log`: отрицательная проверка с сохранённым прежним обработчиком воспроизводит точную ошибку из журнала пользователя.
- `build/language-f3-fixes/mixin-apply.log`: исправленные обработчики проходят применение.
- `build/language-f3-fixes/artifact-check.json`: проверка соответствия исправленных классов готовому JAR и точечных изменений исходников.

Это не проверка полной сборки модов в работающем клиенте и не новая визуальная приёмка. Клиент по прежнему указанию пользователя не запускался; новые кадры Minecraft после исправления не снимались. Присланные пользователем кадры относятся к состоянию до исправления.
