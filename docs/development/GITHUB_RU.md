# Публикация исходников

Рабочий проект: `F:\DarkWinter`. Для нового репозитория готовится чистый снимок `build/github-ready-20261031-compact` на локальной ветке `main`. Старые Git-коммиты, локальные данные и сборки в него не переносятся. Commit и push выполняются только по отдельной команде владельца.

## Состав

Публикуются исходники мода и Visuals-модуля, ресурсы, исходники лаунчера, Gradle wrapper, конфигурация обычной сборки, актуальная документация и обязательные лицензии.

Каталоги с именами `tools` и `tests` исключены через [.gitignore](../../.gitignore). Они остаются на компьютере разработчика: там сохранены Lab, проверки, генераторы ресурсов и средства обслуживания сервисов. Если локальные каталоги доступны, Gradle подключает их дополнительные задачи. Обычная сборка опубликованного проекта от них не зависит.

Контракт Visuals, обязательный для сборки, находится в `modules/darkwinter-visuals/config/pipeline_contract.json`. Старые отчёты, промпты и промежуточные материалы сохранены локально внутри исключённой `.darkwinter-lab/docs-archive-20261031/`.

## Перед отправкой

1. Собирать и проверять именно чистый снимок, в котором нет `tools/tests`.
2. Проверить отсутствие профилей, миров, журналов, ключей, резервных копий и готовых бинарных сборок в индексе.
3. Использовать для нового GitHub-репозитория чистую историю снимка, а не прежнюю историю рабочего каталога.
4. Создать репозиторий и выполнить первый commit/push после команды владельца.

Обычная сборка описана в [руководстве разработчика](BUILD_RU.md). Локальные инструменты аудита и экспорта остаются у разработчика и не входят в публикацию.
