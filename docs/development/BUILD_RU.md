# Сборка и запуск

Игровой проект использует Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.163.0+26.3 и Java 25. Актуальные версии заданы в [gradle.properties](../../gradle.properties), требования компилятора — в [build.gradle](../../build.gradle).

## Мод

Текущая сборка мода с WKE предназначена для Windows x64. Установите JDK 25 x64 и направьте `JAVA_HOME` на него. Откройте корень репозитория в IDE как Gradle-проект. Используйте прилагаемый wrapper, не меняя закреплённые версии зависимостей:

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

`build` автоматически подготавливает Zig 0.14.1 и Vulkan-Headers 1.3.296 в игнорируемом каталоге `build/`. Загрузки проверяются по закреплённым размерам и SHA-256; системный `PATH` не изменяется. Для первой сборки нужны доступ к репозиториям Gradle/Maven, `ziglang.org` и `raw.githubusercontent.com`. Локальные каталоги `tools/tests` для обычной сборки не нужны.

Отдельная проверка собранного JAR, нативных библиотек и ресурсов WKE:

```powershell
.\gradlew.bat wkeVerifyPackage
```

Версия мода для DarkWinter pre-0.0.3 — `0.0.3-pre`; она задаётся в `gradle.properties` и попадает в метаданные и имя JAR.

Команды выполняются из корня репозитория. Результат сборки находится в `build/libs/`; содержимое `build/`, игровые данные и локальные отчёты в репозиторий не входят. При запуске из IDE выберите JDK 25 для самого Gradle, а не только для редактора исходников.

[Vulkan](VULKAN_RU.md) выбран начальным значением графического API для новых настроек. Дальнейшие клиентские проверки выполняются на Vulkan; смена API требует перезапуска.

Обычные сохранения и проверочные миры не нужно копировать в исходники. Перед заменой игрового JAR завершите Minecraft; для совместной игры на обоих ПК нужна одинаковая сборка.

## Лаунчер

Требуются Windows x64, MSVC C++ tools и Windows SDK. Rust закреплён файлом [rust-toolchain.toml](../../darkwinter-launcher/rust-toolchain.toml), зависимости — `Cargo.lock`. Из каталога `darkwinter-launcher`:

```powershell
cargo build --release --locked
```

Исполняемый файл — `target/release/DarkWinterLauncher.exe`. Возможности и незавершённые части описаны в [руководстве лаунчера](../launcher/README_RU.md).

## Границы проверки

Успешная компиляция не заменяет запуск настоящего клиента и проверку интерфейса, рендера или сетевой игры. Для проверки сохранений используйте собственную отдельную копию. Исторические тестовые стенды, локальные инструменты, результаты и снимки не входят в публикуемый состав исходников. Указания по публикации: [GitHub](GITHUB_RU.md).
