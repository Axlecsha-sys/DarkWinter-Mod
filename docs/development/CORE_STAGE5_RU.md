# Этап 5 — персонаж самостоятельного C++/Vulkan-клиента

Дата: 07.11.2026. Ветка: develop/с++.

## Результат

В DarkWinter_Test работает локальный персонаж без JVM и MinecraftServer.
Коллизии берутся из фактического BlockState.getCollisionShape; визуальная
геометрия хвои не превращается в сплошные кубы. Сетка импортированного мира
конечная, 96 × 96 блоков. На границе введена коллизия, выше мира остаётся небо.

Вместо свободного полёта по умолчанию доступны шаг, бег, прыжок, скольжение
вдоль стен и плавное зашагивание. Физика выполняется с фиксированным шагом
120 Гц, отображение интерполируется. Длинный кадр ограничивает наверстывание
до 0,25 секунды; пауза останавливает симуляцию и часы.

Правила перенесены по SprintStamina и MotionSettings: ходьба около 3,54 м/с,
бег около 5,61 м/с, задний ход ×0,60, боковой ×0,80, разгон около 0,14 с,
перестановка опоры при реверсе 0,10 с. S имеет приоритет над бегом.
Режим бега включается только Shift, двойное W его не запускает.
Запас сил 150; расход бега 8/с, прыжков 10/18; интервал прыжков 0,9 с.
Восстановление 12/с в движении и 18/с стоя, с задержками 1/1,5 с.
После истощения требуется полное восстановление.

Подъём на естественные уступы до 1,125 блока занимает 0,25 с.
Проверяются коллизии, высота и место для головы; отпускание движения,
разворот и Space прерывают подъём. Стволы, ветки и предметные поверхности
не считаются естественной ступенью. Границы мира тоже не дают взбираться.
Это первый нативный контроллер: полного совпадения каждой детали движения
Fabric-версии пока не заявляем.

## Персонаж и камера

Экспортированы точные полигоны ThirdPersonBodyModel.createRoot(false),
их дочерние части, UV и northern_survivor.png. Модель содержит 5824
треугольника; это базовое тело в белье. Одежда и экипировка пока остаются
следующим этапом. Шесть основных групп анимируются по реальному пути,
в стене ноги не продолжают шагать. Полная артикуляция локтей/коленей
и отдельные анимации действий ещё не перенесены.

Модель имеет собственный небольшой BVH и отдельный статический буфер GPU.
Трансформации задаются через 128-байтовые push constants; геометрия чанков
и тело каждый кадр не пересобираются и не загружаются заново.

Камера за плечом приближается у препятствий и переходит в первое лицо
в тесном месте. F4 переключает перспективу. В третьем лице действуют
сглаживание 0,085 с и ограничения 210/150 градусов в секунду. В первом
лице мышь непосредственная. Потеря фокуса открывает паузу и отпускает ввод.
Доступна отладочная свободная камера F6.

## Интерфейс, звук, взаимодействие и сохранения

Сохранены меню, пауза, шрифт и HUD времени из предыдущего этапа.
Индикатор выносливости использует оформление и значок мода.
Не показаны фиктивные показатели ещё не перенесённого выживания.

Загружены 16 существующих шагов Minecraft по снегу, камню, грунту и дереву.
Сборка однократно декодирует OGG в PCM; EXE использует Windows waveOut.
В клиенте нет Java, STB, декодера OGG и новой сторонней зависимости.
Буферы голоса ограничены; левый/правый шаг немного смещён по каналам.
При отсутствии аудиоустройства мир продолжает работать без звука.
Автопрогоны скрытого окна намеренно беззвучны.

Взаимодействие проверяет досягаемость от персонажа и препятствия между ним
и целью. Сплошной блок нельзя поставить через тело. Tab пока открывает
редакторскую палитру материалов, а не полноценный инвентарь.

STATE2 сохраняет ноги, направление взгляда, скорость, выносливость,
истощение, задержки и опору вместе с изменённым DWV и временем.
STATE1 читается с подбором безопасного положения. Существующие файлы
сохранений не перезаписываются.

Повторная генерация тестового мира выявила разный порядок регистрации
одинаковых состояний блоков. export/palette-order.json фиксирует прежние
170 числовых ID; данные нового экспорта явно переставляются по именам.
Добавление нового состояния требует явной миграции. Проверяется загрузка
замороженного мира этапов 3/4 с новыми ресурсами.
Контроль неизменности иерархии теперь сравнивает итог с тем же текущим
экспортом до оптимизации, build/core/source-scene/current. Старый набор
для измерений рендера сохранён отдельно и не подменяется этим контролем.

## Проверки

- Нативные сценарии: опора, прыжок, голова, снег/полублок, стена, ствол,
  плавный подъём и его отмена, диагональ, реверс, расход/восстановление,
  отрицательные координаты, ограничение догоняющих тиков и сохранение.
- Один маршрут сравнивается при отображении 30, 60 и 144 Гц.
- Настоящий Win32/Vulkan-процесс принимает W, Shift, Space, Esc, Enter и F4;
  проверяются пройденный путь, прыжок, пауза и восстановление состояния.
- Существующие проверки редактирования, отмены устаревших задач,
  сохранений и CPU/GPU-попаданий по миру сохранены.
- CPU/GPU-оракул проверяет мир; тело проверяется по экспортированным данным
  и контрольным кадрам, а не выдаётся за охваченное тем же оракулом.
- Аудит проверяет запуск без Java в окружении, целостность пакета,
  отказ на повреждённых ресурсах и совпадение содержимого ZIP.
- Vulkan validation layers на машине не установлены. Это ограничение
  графической проверки остаётся; отсутствие ошибок API этим не доказано.

Команды:

~~~powershell
.\gradlew.bat coreVerifyPlayer coreVerifyWorld coreCheckScene
.\gradlew.bat coreAuditWorld build
.\gradlew.bat coreRunWorld
~~~

Свежие результаты: build/core/latest-player.json,
build/core/latest-world.json, build/core/latest-world-audit.json.
Кадры: player-runs/<запуск>/walking.png, survivor.png, first-person.png.
Время GPU относится к проходу, CPU — к обновлению контроллера; это не
сравнение FPS Minecraft и самостоятельного клиента.

## Подтверждённый итог

coreAuditWorld build завершились успешно. 1717 нативных проверок
включают 1681 проверку наличия секций испытательной площадки; это не
1717 разных игровых сценариев. Отдельно прошли 266 проверок сцены,
в том числе 170 проверок стабильности имён старой палитры.
Автопрогон в реальном окне прошёл 3,400 м и выполнил один прыжок;
пауза и точное восстановление состояния подтверждены.
В этом коротком маршруте фаза шага не пересекла порог звука на земле,
поэтому он не доказывает слышимость шагов. Скрытые прогоны беззвучны;
аудиопакет проверен декодированием и нативной загрузкой.

На контрольном маршруте обновление контроллера занимало медиану
0,0077 мс, p95 0,0093 мс; это CPU двух тиков за отображаемый кадр
на данной сцене, без GPU и полной стоимости кадра.
Оракул мира в прогоне персонажа: 587 проверенных лучей, 0 расхождений.
Аудит проверил 11 повреждённых входов, запуск без Java и идентичность
файлов в ZIP. Готовый пакет: build/core/package/DarkWinter-World-Windows-x64.zip.
